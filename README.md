# .github

Organization-level files for [SkapaCraft](https://github.com/skapacraft).

- **[`profile/README.md`](profile/README.md)** is what GitHub renders on the
  organization page at [github.com/skapacraft](https://github.com/skapacraft).
  It is the only place that page can be edited from: an organization does not
  use a repository named after itself the way a personal account does.
- **[`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md)** is the default for every
  repository in the organization that does not carry its own copy.

There is no code here. Each project lives in its own repository, with its own
`LICENSE`, `SECURITY.md` and `CONTRIBUTING.md`.
